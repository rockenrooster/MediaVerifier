# Detection rates

Generated by `CorruptionBenchmark` (subplan 15, Detection-rate benchmark; task T-05) with
`MEDIAVERIFIER_UPDATE_DOCS=1 dotnet test --filter FullyQualifiedName~CorruptionBenchmark`. Each cell of the
corruption matrix is repeated at 50 seeded positions between 30 % and 70 % of the file (truncations cut
within 5 points of the listed fraction). A file counts as detected when it has an open damage finding
(`COR-*`, `GEN-UNREADABLE`, `GEN-EMPTY`, `GEN-ZEROFILL`, `GEN-UNRECOGNIZED`) after a scan at that depth;
depths are cumulative. **Fingerprint** damages a file that already has a baseline, keeps its modified
time and counts `INT-ROT` after a verification (size-neutral mutations only; a truncation changes the size,
which is reported as a modified file instead).

Targets: truncation 100 % at Standard, and at Quick for formats with a declared length; checksummed
formats (FLAC, PNG, Ogg) 100 % at Standard; fingerprint 100 %. Every other cell may not fall more than
five points below this table.
